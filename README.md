# YukiUI-wiki

The documentation site for [YukiUI](https://github.com/Kitty-Hivens/YukiUI), hosted [here](https://kitty-hivens.github.io/YukiUI-wiki).

> Currently, this project is based on Starlight, which is based on Astro.
> The website is hosted on GitHub Pages.

**The development and contribution about this repo is documented [here](https://kitty-hivens.github.io/YukiUI-wiki/en/dev/doc-site).**

> If the site is unavailable for some reason, see its source file [here](https://github.com/Kitty-Hivens/YukiUI-wiki/blob/main/src/content/docs/en/dev/doc-site.md).

## History

Forked from [dots-hyprland-wiki](https://github.com/end-4/dots-hyprland-wiki), the documentation site of the upstream project this shell is based on. That site started from [dots-hyprland#246](https://github.com/end-4/dots-hyprland/issues/246), and its contents came from the README and built-in wiki of the upstream repo and the README of [dots-hyprarch](https://github.com/clsty/dots-hyprarch).
